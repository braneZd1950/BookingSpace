# PDF fontovi (DejaVu Sans)

Koristi ih `client/src/lib/archivePdf.js` za arhivske PDF-ove s hrvatskim znakovima.

Datoteke se kopiraju u `client/dist/fonts/` pri `vite build` — na Renderu moraju biti u repou (ne gitignore).

- `DejaVuSans.ttf`
- `DejaVuSans-Bold.ttf`

Licenca: Bitstream Vera / DejaVu (slobodna uporaba). Izvor: [dejavu-fonts](https://dejavu-fonts.github.io/).
