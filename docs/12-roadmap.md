# Post-MVP Roadmap

Do not build phase 3 or 4 before proving the core booking product.

## Phase 1.5

After real pilot feedback:

- waitlist
- email notifications
- recurring bookings
- better staff permissions
- attendance check-in
- membership reminders

## Phase 2

- online payments
- automatic membership renewal
- packages
- promo codes
- advanced reports
- SMS
- Google Calendar integration

## Phase 3

- custom domains
- white-label
- multiple locations
- advanced staff scheduling
- resource and equipment management
- API integrations

## Phase 4

Platform and network features:

- cross-studio discovery
- studio search
- favorites
- unified customer profile
- optional multi-studio memberships
- marketplace features
